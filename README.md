## What it does

`main.py` (Python 3, no dependencies, no network) writes exactly one emoji —
the dream vacation — to `/output/entry.txt`:

> 🏖️

One emoji, nothing else. The beach with umbrella is the most universal
shorthand for a dream vacation: sand, sea, sun and shade in a single glyph,
a postcard a stranger reads at a glance. It names the place (not the means
of getting there, like a plane, and not a moment, like a sunset), it is
personal and specific — that one afternoon under the umbrella, nowhere to
be — and it reads instantly across cultures and screens, clear at small
size with nothing to explain.

The program validates the entry before writing it: exactly one character,
not whitespace, within the gate's 1–8 character limit, written as UTF-8
with no trailing newline and no extra text.

## Run

```sh
python3 main.py
# writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
